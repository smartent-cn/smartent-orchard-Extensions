# Projects in the UI Testing Toolbox

The UI Testing Toolbox encompasses the following projects:

- `Smartent.Test.UI`: Contains all features used for UI testing. This is the project that your test projects need to reference.
- [`Smartent.Test.UI.AppExtensions`](../../Smartent.Test.UI.AppExtensions/Readme.md): UI testing-related extensions for the web app under test.
- [`Smartent.Test.UI.Shortcuts`](../../Smartent.Test.UI.Shortcuts/Readme.md): Provides some useful shortcuts for common operations that UI tests might want to do or check, e.g. turning features on or off, or logging in users. If you utilize these shortcuts then your web projects needs to reference this project to load as an Orchard Core module.
- [`Smartent.Test.UI.Samples`](../../Smartent.Test.UI.Samples/Readme.md): Example UI testing project.
- [`Smartent.Test.UI.Tests.UI`](../../Smartent.Test.UI.Tests.UI/Readme.md): UI Tests for the UI Testing Toolbox.
