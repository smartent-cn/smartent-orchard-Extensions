# Smartent MSBuild SDK - Orchard Core Module

## About

MSBuild SDK for Orchard Core modules that also use [Smartent Helpful Libraries](https://gitee.com/smartent/smartent-training-demo-modules Using this instead of `Microsoft.NET.Sdk.Razor` greatly reduces the project file boilerplate. See [Using MSBuild SDKs](../Docs/UsingMSBuildSdks.md) for information on how to use it.
