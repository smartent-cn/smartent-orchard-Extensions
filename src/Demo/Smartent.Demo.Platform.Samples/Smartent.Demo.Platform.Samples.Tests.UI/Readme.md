# Smartent Helpful Libraries for Orchard Core - Samples - UI Test Extensions
> **中文说明**: [Readme-CN.md](Readme-CN.md)


UI tests verifying Smartent Helpful Libraries Samples behavior, and thus testing some Smartent Helpful Libraries features at a high level.

Since the project depends on `Smartent.Demo.Platform.Samples`, for it to be published to NuGet, the Samples project would also need to be published, what doesn't make much sense. So, this project isn't published to NuGet.
