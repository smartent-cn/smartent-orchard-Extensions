# Smartent Orchard Hosting - Tenants Management for Orchard Core - UI Test Extensions

## About

Extension methods that test tenants management for Orchard Core, with the help of [Smartent UI Testing for Orchard Core](https://gitee.com/smartent/smartent-training-demo-modules

Call these from a UI test project to verify the module's basic features; as seen in [Open-Source Orchard Core Extensions](https://github.com/smartent-cn/smartent-orchard-Extensions).
