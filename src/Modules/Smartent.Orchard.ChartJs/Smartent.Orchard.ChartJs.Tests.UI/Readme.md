# Smartent Orchard Chart.js for Orchard Core - UI Test Extensions

## About

Extension methods that test various features in Smartent Orchard Chart.js for Orchard Core, with the help of [Smartent UI Testing for Orchard Core](https://gitee.com/smartent/smartent-orchard-Extensions)
Call these from a UI test project that also references `Smartent.Orchard.ChartJs.Samples` to verify the module's basic features; as seen in [Open-Source Orchard Core Extensions](https://github.com/smartent-cn/smartent-orchard-Extensions).
